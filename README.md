I build Java backends, and lately I've been focused on one thing: taking LLM applications from demo to production — multi-agent orchestration, RAG retrieval, long-session context management, and resilience engineering.

## 🔭 What I'm Building

**[mockInterview](https://github.com/Sakura-hexo/mockInterview)** — a multi-agent mock interview platform built independently: upload a resume and a job description, and an AI interviewer conducts multi-round questions with follow-ups, wrapping up on schedule; when it's done, the report pipeline generates a per-question scored review with tailored reference answers. A complete backend engineering exercise — layered architecture, RAG-powered question retrieval, streaming output, load testing and monitoring. Details in the repo README.
